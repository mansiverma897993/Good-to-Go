# 🚀 GTG (Good To Go) – Open Source Discovery Platform

> A comprehensive full-stack web application designed to help students and developers discover and contribute to open source projects with ease.

---

## 🌍 Overview

**GTG** (Good To Go) is a one-stop open-source discovery platform that curates and aggregates opportunities from popular programs like **Google Summer of Code (GSoC)**, **GirlScript Summer of Code (GSSoC)**, **Script Winter of Code (SWoC)**, **Hacktoberfest**, **Summer of Bitcoin**, and more.

It empowers aspiring developers and students to:
- Explore real-world open source programs.
- Discover beginner-friendly projects.
- Learn how to contribute effectively.
- Stay updated with deadlines and requirements.

---

## ✨ Features

- 🔍 **Discover Programs** – Find open-source programs and hackathons across the globe.  
- 🧠 **Filter by Skills / Tech Stack** – Quickly find projects that match your skills.  
- 🗓️ **Deadline Reminders** – Stay updated with ongoing and upcoming programs.  
- 💬 **Community Discussions** – Connect with contributors and mentors.  
- 🌐 **Dynamic Aggregation** – Automatically fetches and lists active open-source programs.  
- 📊 **Dashboard View** – See insights, project stats, and participation data.  

---

## 🏗️ Tech Stack

**Frontend:**  
- Next.js (React Framework)  
- TypeScript  
- Tailwind CSS  
- ShadCN/UI  

**Backend:**  
- Node.js / Express  
- MongoDB / Prisma (depending on implementation)  
- REST or GraphQL API  

**Other Tools:**  
- GitHub REST API for program listings  
- Vercel / Netlify for deployment

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash

# 2. Move into the project directory
cd Good-to-Go

# 3. Install dependencies
npm install --legacy-peer-deps

# 4. Run the development server
npm run dev
